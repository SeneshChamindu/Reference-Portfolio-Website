# Prabath Kumara design system

## Visual direction

- Lead with the dark green-black canvas and neon-lime signal color.
- Use the centered visual stage as a focal point, with large display type above
  it and compact technical metadata below it.
- Treat the grid, scanlines, restrained glow, and thin borders as atmosphere;
  never let them compete with the content.
- Use cyan only as a secondary technical accent. Lime remains the primary
  action, status, and emphasis color.

## Typography

- Use Manrope for display, body, navigation, and action copy.
- Use DM Mono for eyebrow labels, metadata, coordinates, tags, and small
  technical annotations.
- Keep display headings large and tightly tracked; keep supporting copy short,
  calm, and readable.

## Composition

- Build generous vertical rhythm around hero and section transitions.
- Pair a large statement with a smaller explanatory note rather than filling
  the page with equal-weight content.
- Use compact cards with clear borders and a single visual focal point.
- Use uppercase mono labels for wayfinding, but reserve them for short phrases.

## Motion

- Prefer slow, low-amplitude motion: float, drift, scan, and reveal.
- Motion should reinforce the cinematic/technical mood without delaying access
  to content or controls.
- Interactive controls must remain obvious and usable on touch screens.

## Content tone

- Be direct, useful, and human.
- Prefer action-oriented labels such as “explore the work” and “start a
  conversation.”
- Avoid generic startup language and decorative copy that does not clarify the
  work.
